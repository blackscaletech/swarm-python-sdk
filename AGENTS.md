# Repository Instructions

- Before maintainer commits, use local Git identity `Blackscale <hello@blackscale.tech>`
  and enable the versioned hooks as described in `CONTRIBUTING.md`.
- Run `sh scripts/check-attribution.sh identity` before committing and
  `sh scripts/check-attribution.sh history HEAD` before pushing.
- Do not invent co-authors or attribute automated work to an unrelated account.
- Preserve genuine outside contributors' attribution and published release tags.
